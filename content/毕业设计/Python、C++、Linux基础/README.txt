使用说明

1. 请解压整个压缩包，不要只抽取 Markdown 文件。
2. 打开“Python_C++_Linux_基础学习笔记_面向双臂VLA毕业设计.md”。
3. Markdown 图片使用相对路径 assets/xxx.png，必须保留 assets 文件夹与 Markdown 文件的相对位置。
4. 推荐使用 Typora、Obsidian、VS Code（安装 Markdown 预览插件）或支持 MathJax/LaTeX 的 Markdown 阅读器。
5. 公式以 $$...$$ 块级 LaTeX 形式书写。

内容说明
- Python：语法、对象引用、函数、类、文件、异常、虚拟环境、NumPy、RGB-D示例。
- C++：编译、类型、引用指针、生命周期、STL、RAII、智能指针、CMake、Eigen、轨迹插值。
- Linux：文件系统、Shell、管道、权限、进程、SSH、网络、资源检查、脚本。
- 配图：10 张项目架构、内存模型、编译流程、文件系统和坐标变换示意图。
